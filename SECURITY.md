# Zgłaszanie problemów bezpieczeństwa

Nie publikuj publicznego issue ze szczegółami podatności, danymi użytkowników ani sekretami.

Jeśli znajdziesz problem bezpieczeństwa, zgłoś go prywatnie przez funkcję raportowania podatności w zakładce **Security** repozytorium GitHub. W zgłoszeniu opisz możliwy wpływ i kroki odtworzenia, ale nie dołączaj prawdziwych haseł ani danych innych osób.
