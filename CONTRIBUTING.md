# Udział w rozwoju

To projekt edukacyjny. Możesz rozwijać go we własnym tempie, a każdą funkcję trzymać na osobnym branchu.

1. Opisz pomysł jako issue albo krótką notatkę.
2. Zrób branch, np. `feature/weekly-goal`.
3. Wprowadzaj małe zmiany i zapisuj je czytelnymi commitami.
4. Uzupełnij dokumentację, jeśli zmienia się sposób uruchomienia lub zachowanie aplikacji.
5. Przed publikacją zmian uruchom testy i sprawdź działanie formularzy w przeglądarce.

Przydatne polecenie do lokalnego uruchomienia: `flask --app learnloop:create_app run --debug`.
